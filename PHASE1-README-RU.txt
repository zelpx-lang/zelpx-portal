ZELPX — Этап 1, отдельная рабочая копия
=========================================

Это отдельная неподключённая рабочая копия. GitHub, Supabase, Vercel и
действующий сайт не изменялись.

Включено:
- index.html и admin.html: поля регистрации и профиля подрядчика — адрес,
  город, штат, ZIP-код, радиус обслуживания, наличие лицензии, номер,
  штат выдачи, тип лицензии и загрузка документа.
- supabase-phase1-contractor-profile.sql: добавочная миграция базы и приватное
  хранилище документов; расширяется триггер создания аккаунта подрядчика.

ВАЖНО:
1. Не публиковать HTML до проверки и применения SQL на тестовом проекте.
2. Географическое распределение лидов по радиусу пока не включено. Это этап 2:
   потребуется серверная RPC-функция, чтобы фильтровать лиды без раскрытия
   контактов заказчика.
3. Существующие записи подрядчиков не удаляются и не перезаписываются.
4. Документы лицензий хранятся в закрытом Storage. Чтение разрешено владельцу
   файла и администратору.
5. При ответе Yes лицензия получает статус pending до проверки администратором.
6. На тестовом проекте нужно проверить регистрацию с подтверждением email,
   создание записи подрядчика, загрузку файла и доступ администратора.


Phase 2 is provided separately in supabase-phase2-location-matching.sql. Apply both migrations only on staging, in order, after review.
