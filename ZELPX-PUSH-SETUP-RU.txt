ZELPX — PUSH-УВЕДОМЛЕНИЯ ЧАТА (РАБОЧАЯ КОПИЯ)
================================================

Что добавлено
- Кнопка добровольного включения уведомлений на страницах подрядчика и заказчика.
- Регистрация Service Worker и подписка браузера на Web Push.
- Новая таблица chat_push_subscriptions с RLS: пользователь управляет только своими подписками.
- Edge Function send-chat-push: при новом сообщении определяет второго участника диалога и отправляет ему push.
- Никакие старые таблицы, сообщения, заявки, аккаунты или политики чата не удаляются.

ВАЖНО
Это подготовленный пакет, НЕ опубликованный сайт. SQL не применён, Edge Function не развёрнута.
Не загружайте весь ZIP в Supabase. Сначала настройте ключи и проверьте на тестовом аккаунте.

ФАЙЛЫ
- supabase-chat-push.sql — добавить таблицу подписок и RLS.
- zelpx-push.js — кнопка и регистрация подписки в браузере.
- zelpx-sw.js — обработка push и нажатия на уведомление.
- supabase/functions/send-chat-push/index.ts — серверная отправка push.
- index.html и customer.html — подключают общий скрипт; старый код сохранён.

НАСТРОЙКА (после отдельного разрешения на публикацию)
1. Создать VAPID-ключи на компьютере с Node.js:
   npx web-push generate-vapid-keys
   Сохранить Public Key и Private Key. Private Key нельзя помещать в HTML или ZIP для публичного репозитория.
2. В zelpx-push.js заменить REPLACE_WITH_VAPID_PUBLIC_KEY на Public Key.
3. В Supabase SQL Editor выполнить supabase-chat-push.sql.
4. Развернуть Edge Function send-chat-push в проекте zelpx-database.
5. Добавить секреты функции:
   VAPID_PUBLIC_KEY = Public Key
   VAPID_PRIVATE_KEY = Private Key
   VAPID_SUBJECT = mailto:адрес-поддержки
   CHAT_PUSH_WEBHOOK_SECRET = длинная случайная строка
   SUPABASE_URL и SUPABASE_SERVICE_ROLE_KEY должны быть доступны функции как стандартные secrets проекта.
6. В Supabase Dashboard → Database → Webhooks создать webhook:
   - Table: public.lead_messages
   - Event: INSERT
   - Type: Supabase Edge Function / HTTP POST
   - Function URL: https://zsrnjkndgbchfxibxiyd.supabase.co/functions/v1/send-chat-push
   - Header: x-webhook-secret: то же значение CHAT_PUSH_WEBHOOK_SECRET
   - Payload: стандартный Database Webhook payload с объектом record.
7. Опубликовать изменённые index.html, customer.html, zelpx-push.js и zelpx-sw.js на хостинге.
8. Открыть сайт по HTTPS под аккаунтом заказчика и подрядчика, нажать «Enable message notifications» и разрешить уведомления.
9. Проверить отправку в обе стороны. Проверить также с закрытой вкладкой.

ПОВЕДЕНИЕ И ОГРАНИЧЕНИЯ
- Push работает только после явного согласия пользователя и при поддержке браузером/ОС.
- На Android Chrome/совместимых браузерах уведомления обычно работают в фоне.
- На iPhone/iPad Web Push для веб-приложения требует iOS/iPadOS 16.4+ и добавления сайта на экран «Домой»; разрешение запрашивается из установленного web app.
- Звук/баннер контролируются настройками уведомлений браузера и телефона. В фоне сайт не может принудительно включить звук, обойти «Не беспокоить» или гарантировать показ баннера.
- Пока пользователь находится на странице, системный звук может зависеть от настроек браузера. В этой версии основной звук — системный звук push-уведомления.
- Уведомление содержит короткий фрагмент текста сообщения; если нужна максимальная приватность на заблокированном экране, замените body в Edge Function на «У вас новое сообщение в ZELPX».
- Нужна одна подписка на каждое устройство/браузер. На другом телефоне пользователь включает уведомления отдельно.

ПРОВЕРКА БЕЗОПАСНОСТИ
- В браузере используется только publishable/anon key.
- Service role key и VAPID Private Key используются только на сервере.
- RLS ограничивает чтение/изменение подписок владельцем user_id.
- Edge Function получает сообщение из Database Webhook и адресует push только второму участнику беседы.
- Не создавайте публичную политику SELECT для всех подписок.

Откат
Если понадобится отключить push, сначала выключите Database Webhook и Edge Function. Таблицу и старые сообщения удалять не нужно. Для удаления только подписки пользователь может отключить уведомления в настройках браузера/телефона.
