ZELPX — Customer Dashboard + телефон клиента

В customer.html добавлен блок My Profile:
- отображает имя и телефон клиента;
- позволяет изменить имя и номер телефона;
- сохраняет изменения в public.profiles (RLS уже разрешает пользователю обновлять собственный профиль);
- обновляет auth user metadata, чтобы регистрационные данные оставались согласованными.

Customer Dashboard уже был отдельной страницей /customer (customer.html); теперь он дополнен редактируемым профилем.

Обнаруженная проблема регистрации:
- текущая функция public.handle_new_user() записывает role='contractor' для всех новых пользователей, даже если customer.html передаёт account_type='customer'.
- SQL-файл supabase-customer-account-role-fix.sql исправляет это для новых регистраций. Существующие роли не меняет.

Порядок:
1. Сделать резервную копию.
2. Применить SQL в Supabase SQL Editor.
3. Опубликовать обновлённый customer.html на Vercel.
4. Проверить вход клиента, профиль, сохранение телефона, создание заявки.
